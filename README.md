# 🧮 C Simple Calculator

My first project built using C programming.

## About

A simple command-line calculator that performs basic arithmetic operations:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## Concepts Used

- Variables and data types
- `printf()` and `scanf()`
- Operators
- Conditional statements
- Basic input/output

## Example

```text
Enter an operator (+, -, *, /): /
Enter two numbers: 49 2
